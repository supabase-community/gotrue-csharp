# Supabase.Gotrue has moved

> [!IMPORTANT]
> This repository is **archived and read-only**. `Supabase.Gotrue` is now developed in the
> **[supabase-csharp](https://github.com/supabase-community/supabase-csharp)** monorepo,
> alongside the other Supabase .NET packages.

- **Source:** [supabase-csharp/packages/Gotrue](https://github.com/supabase-community/supabase-csharp/tree/master/packages/Gotrue)
- **Issues & pull requests:** [open them in the monorepo](https://github.com/supabase-community/supabase-csharp/issues)

## The NuGet package is unchanged

Only the repository has moved — [`Supabase.Gotrue`](https://www.nuget.org/packages/Supabase.Gotrue/) is still
published from the monorepo, so nothing changes for consumers:

```sh
dotnet add package Supabase.Gotrue
```
